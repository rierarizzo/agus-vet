# Agus Vet

Veterinary clinic website built with Astro.

## Getting Started

```bash
npm install
npm run dev
```

## Commands

| Command | Description |
|---------|-------------|
| `npm run dev` | Start development server |
| `npm run build` | Type check and build static site |
| `npm run preview` | Preview built site locally |

## Tech Stack

- Astro 5
- TypeScript
- Static output
